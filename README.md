Запросы уходят зашифрованными сразу на несколько независимых серверов; побеждает первый
настоящий ответ. Каталог из ста тысяч резолверов проверяется не на слово, а измерением:
задержка, честность ответов, DNSSEC, подмена несуществующих имён, фильтрация.

**Без телеметрии, без аккаунта, без собственных серверов.** Всё, что программа знает, она
измерила на вашей машине и хранит там же.

## Зачем это сейчас

Провайдеры начали блокировать **шифрованный DNS** — DoH у Google и Cloudflare. Пока ваш DNS
зашифрован, провайдер не видит, к каким сайтам вы обращаетесь, и не может блокировать их
прицельно. Сломать шифрованный DNS — значит вернуть устройство на открытый DNS провайдера,
где виден каждый запрос.

Программа построена против этого сценария:

- **не зависит от одного оператора** — в каталоге сотни адресов, а не два;
- **не зависит от одного транспорта** — заблокировали DoH по имени сервера, остаются DoT
  (порт 853), DoQ (имени в открытом виде нет вовсе) и DNSCrypt (SNI нет в принципе);
- **пробивает фильтр по имени** — режет TLS-рукопожатие так, что имя не попадает целиком ни
  в один сегмент;
- **измеряет, а не гадает** — проверяет каждый транспорт по-настоящему с вашего канала.

Порядок действий — [«DoH заблокировали»](https://mintyextremum.github.io/ME.DNSJumper/blocking/).

## Что умеет

| | |
|---|---|
| **Шесть транспортов** | DoH, DoT, DoQ, DNSCrypt v2, Do53 и ODoH через ретранслятор |
| **Обход фильтра по SNI** | Разрезание рукопожатия внутри имени; стратегия подбирается и запоминается по каждому серверу |
| **Проверка линии** | Что доходит именно с вашего канала — измерением, а не предположением |
| **Разбор сайта** | Подмена DNS, фильтр по имени или выброшенный адрес — и кто из них что лечит |
| **Проверка подписей DNSSEC** | Своими силами, от вшитого корневого ключа вниз по зонам |
| **Один запрос вместо трёх** | Хеджирование: остальные подключаются, только если первый молчит |
| **Перехват всех имён** | Через политику DNS-клиента (NRPT), не трогая адаптеры |
| **Соседство с zapret** | Видит его, не мешает и умеет передать домен в его хостлист |
| **Кэш, переживающий блокировку** | serve-stale (RFC 8767) и сохранение между запусками |
| **Журнал и отчёт о проблеме** | С отбором по ошибкам, кэшу и задержке; отчёт одним текстом |
| **Профили и маршрутизация** | Свой набор серверов по сети, времени, программе или адаптеру |

## Установка

1. Скачайте `.msi` со [страницы релизов](https://github.com/mintyextremum/ME.DNSJumper/releases/latest).
2. Запустите. Windows 10/11, x64.
3. Для автономной работы: **Настройки → Запуск с Windows → С правами администратора**, затем
   **Автономная работа → Сразу направлять систему на резолвер**.

Обновляется само. Пакет проверяется по подписи — установщик, не проходящий проверку по
ключу, вшитому в программу, установлен не будет.

Подробности — [«Установка»](https://mintyextremum.github.io/ME.DNSJumper/install/).

## Чего программа не делает

- **Не трогает чужие пакеты.** Всё, что она режет, — её собственные DNS-соединения. Десинк
  произвольного трафика требует драйвера и делается через
  [zapret](https://github.com/bol-van/zapret), с которым она уживается.
- **Не обходит блокировку по IP.** Если сервис отказывает, посмотрев на ваш адрес, DNS
  бессилен — нужна смена видимого адреса.
- **Не включает ECH в браузере.** Для этого браузеру нужен собственный защищённый DNS.

Полный список — [«Границы»](https://mintyextremum.github.io/ME.DNSJumper/limits/).
